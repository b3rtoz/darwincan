# Engineering notes

Records kept while darwinCAN was built. They are written for whoever works on the project next, not as an introduction: start with the [README](../../README.md) and the guides in [`docs/`](..) instead.

| File | What it is |
|---|---|
| [hardware-validation-log.md](hardware-validation-log.md) | Every run against real adapters, by date: the bench, what was tested and measured, the faults found and their fixes, and what is still open |
| [decisions.md](decisions.md) | The design decisions, in the order they were made, with their reasons |

Both are kept as they were written. Where a later entry corrects an earlier one, the later one is right.
